# Exercícios DOM

Lista de exercícios propostos para praticar DOM:

1. Manipular selecionadores
   - Usar `querySelector` e `getElementById` para alterar texto de elementos.
2. Criar elementos dinamicamente
   - Criar uma lista com itens a partir de um array.
3. Eventos e listeners
   - Criar botões que mostram informações diferentes ao clicar.
4. Delegação de eventos
   - Implementar listener único para uma lista dinâmica.
5. Validação de formulários
   - Validar campos antes de enviar e mostrar mensagens.
6. Toggle de classes
   - Alternar classes para mostrar/ocultar painéis.
7. Trabalhar com atributos
   - Ler/escrever `data-*` e atributos `src`, `alt`.
8. Animações simples
   - Mover um elemento usando `requestAnimationFrame`.

Sugestões de como entregar:
- Criar um arquivo por exercício em `dom/exercises` ou em `dom/examples`.
- Incluir um pequeno `index.html` para testar cada exercício no navegador.
